## Verificação e correção do pacote XSD

O primeiro deploy da alpha.8 concluiu o build e serviu o frontend, mas a verificação real do endpoint XSD recebeu HTTP 503 com código -1. A dependência `xmllint-wasm` cria um Worker e carrega seu binário por caminho dinâmico. Uma reprodução em diretório temporário, com entrada/Worker mas sem o binário, produziu `WASM Abort`/ENOENT e o mesmo código -1.

`vercel.json` passou a incluir `node_modules/xmllint-wasm/**` nos arquivos da função, mantendo os demais includes e os limites existentes. A regressão executa o pacote isolado com os recursos declarados: XML positivo é aprovado e negativo é reprovado. Schemas oficiais, hashes, biblioteca, regras fiscais, endpoints e respostas não foram alterados.
